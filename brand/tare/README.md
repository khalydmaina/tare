# Tare Brand Kit 1.1

Forensic trading terminal. Not another LLM judge.

## Open first
- `Tare_Brand_Kit.pdf` — 15-page brand book
- `tokens/tokens.css` + `tokens/tokens.json`
- `logos/` — icon, wordmark, lockups, favicons, SVG

## Logo system (locked)
- **App icon:** scale — white gross mass, red net mass (`#EF4444`), capsule beam, down-triangle. Squircle tile.
- **Wordmark:** lowercase `tare` in Poppins Bold. No ®.
- **Tight spaces:** wordmark only.
- **Favicon / avatar:** scale only.

## Name
**tare** (tair). Verb + measurement.
Gross = stated confidence. Tare = Inspector correction. Net = calibrated probability.

Primary line: *Zero the confidence. Weigh the record.*

## Color is a verdict
- Green `#22C55E` — guarded / survived the gate
- Red `#EF4444` — shadow / veto / harm, and the icon’s net mass
- Everything else is black / gray / white

## Type
- Wordmark: Poppins Bold
- UI / body: IBM Plex Sans
- Data / hashes: IBM Plex Mono
